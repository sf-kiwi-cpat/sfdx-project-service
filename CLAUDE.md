# SF Project Service — Claude Code Notes

## Git and Gitignored Files

**Never use `git add -f` to force-add gitignored files.** If a file is in `.gitignore`, that exclusion is intentional. Bypassing it with `-f` puts files into source control that should not be there.

Files that are intentionally gitignored and must never be committed:

- `.agents/review-*.md` — code review reports generated by `/review-code`. These are local working documents, not source artifacts.
- `.agents/.code-review-draft.md` and `.agents/.qa-draft.md` — intermediate agent drafts, deleted after the skill merges them.

If a git operation fails because a file is gitignored, stop and think about why it's excluded rather than forcing it through.

## Review Reports

Code review reports (`.agents/review-N.md`) are local-only. The `/review-code` skill writes them to `.agents/` for the developer's reference during a review session. They are not committed to the branch and do not appear in PRs.
